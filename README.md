# Free Tool Mate

Free browser tools for PDF, images, JSON, SQL, and text. Files stay on your device. No sign-up.

**Site:** https://freetoolmate.com/

## PDF editor

[PDF Editor](https://freetoolmate.com/tools/pdf-editor) opens a PDF in the browser. You can:

- Click existing text and change it
- Add new text, with bold, italic, size, font, and colour
- Erase content
- Find and replace
- Add form fields, a signature, images, stamps, and shapes
- Highlight, underline, and draw
- Zoom, rotate, insert, or remove pages
- Download the edited PDF

Nothing is uploaded. A file can be up to 20 MB and 40 pages.
